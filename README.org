** Lecture Information


- *WARNING:* This is the content only covered by me as this lecture is shared by
  Prof. Can Dede and Benjamin Massow, M.Sc.

The goal of this lecture is to give you an introduction to the world of mobile
robotics with an emphasis on its programming.

The outcome of this course is threefold, which are as follows:

1. An understanding of the Localisation and Mapping problem, which is one of the
   primary problems of designing an intelligent mobile robot. Its implementation
   requires a thorough understanding of advanced statistical methods (i.e.,
   extended kalman filter, bayesian filter) which this lecture will also cover.
   
2. Working with Linux, an open-source operating system which runs majority of
   computers across the world from a simple embedded device to powerful
   supercomputers. The part of the lecture will give a brief introduction to
   different commands useful in Linux to create the necessary base for working
   with ROS.

3. The Robot Operating System (ROS), an industry standard, programming interface
   to create standardised communication with robots. To this end, a strong
   foundation will be built, starting from its unique terminologies (Node,
   Action, Server) to working with visualising software such as RViz. Through
   these activities/lectures students will also gain significant experience
   working with Python, YAML, XML.
